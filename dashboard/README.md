# Power BI Dashboard

The project includes the supplied dashboard preview as `dashboard_preview.pdf`.

The dashboard covers:

- Average Rating
- Customer Count
- Average Purchase Amount
- Customers by Subscription Status
- Revenue and Sales by Category
- Seasonal distribution
- Revenue by Age Group
- Purchase Frequency by Age Group
- Interactive filters for subscription status, gender, category, and shipping type

The current preview reports an average rating of **3.75**, customer count of approximately **4K**, and average purchase amount of **$59.76**.
